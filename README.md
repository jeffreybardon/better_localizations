An incremental patch to be used on top of thpatch's lang_en.  
Contains:  
  * many spellcard name changes, mostly for better accuracy but sometimes to restore older names.
  * a few song name changes, for the same reasons
  * some older dialogue I think sounded better, most notably Satori's mid-fight dialogue
  * reversions of some recent changes to lang_en that created inconsistencies within a game
  * corrections for several errors and typos I found while doing this, mostly in ISC

Thanks to KSS, Hourai, TESM, and anna says hi for some thoughts and input during the process of making this, and FarawayVision for "old_spell_names" that showed how simple making this would actually be.

If there are other things that should be included in this, let me know - it's easy to update!
